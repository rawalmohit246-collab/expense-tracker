# Expense Tracker (Java)

A simple console-based Expense Tracker application built using Java.

## Features
- Add daily expenses
- View all expenses
- Category-wise expense summary
- File-based data storage

## Technologies Used
- Java
- File Handling
- OOP Concepts

## How to Run
1. Clone the repository
2. Open in IntelliJ IDEA
3. Run Main.java
